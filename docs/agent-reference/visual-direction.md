# Visual Direction Reference

- Style: calm, clinical, professional.
- Background: `#f9f9f8`.
- Surfaces: `#ffffff`, `#f3f4f3`, `#eeeeed`.
- Primary: `#415f76`, hover/container `#5a7890` or `#2b4a60`.
- Success: `#4c6455`, container `#cbe6d4`.
- Error: `#ba1a1a`, container `#ffdad6`.
- Typography: Source Serif 4 for headings, Manrope for UI.
- Shape: 8px controls, 16px cards/panels.
- Avoid loud gradients, dark themes, clutter, fake data, or marketing-style pages.
- Stitch assets live under `storage/app/stitch/11237689929679384621/`.
- Public UI images live under `public/images/`.
