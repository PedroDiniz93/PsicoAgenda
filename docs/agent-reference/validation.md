# Validation Reference

- `npm run build`
- `php -l path/to/file.php`
- `php artisan test`
- `php artisan route:list`
- `php artisan serve --host=127.0.0.1 --port=8000`

The app is normally available at `http://127.0.0.1:8000`.

## Notes

- Local tests may be limited by available PHP extensions; report exact failures.
- `public/build` is generated by Vite and may change after `npm run build`.
